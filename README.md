# Humi & Friends

Responsive one-page website starter for HUMI & FRIENDS.

## Structure

- `index.html` — page structure and whitelist form
- `style.css` — responsive desktop/mobile styling
- `script.js` — navigation, wallet validation and success popup
- `assets/desktop-bg.png` — supplied desktop background
- `assets/mobile-bg.png` — supplied mobile background
- `assets/art-1.jpg` through `assets/art-5.jpg` — supplied ART images

## Run

This is a static site. Upload the files to the GitHub repository and connect the repository to Vercel.

No build command is required for this version.

## Important

The whitelist form currently shows the requested success popup locally. Google Sheets / Apps Script submission should be connected after the frontend is confirmed against the final UI.

Success message:

"Your Application to become HUMI's friend is in the Queue."
